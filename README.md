# Typescript Playwright Framework
These tests cover actions performed on the site https://demoqa.com/
## Framework structure

[playwright.config.ts](playwright.config.ts) is the main file in which the conditions for the test are set parametrically 

[tsconfig.json](tests%2Ftsconfig.json) - conditions for executing the script type

[pages](pages) - Project Pages

[tests](tests) the folder contains UI/API tests

## Get Started

npm install -D @playwright/test

npx playwright test
